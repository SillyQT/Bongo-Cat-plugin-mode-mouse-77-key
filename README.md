# Bongo Cat Plugin - Mouse + 77-Key Mode

This is a modified version of the **Bongobs Cat Plugin 0.2.01** for OBS Studio.

It adds a new mode: the cat follows **mouse movement** and works with a **77-key keyboard** layout.

## Based on

- Original project: [Bongobs-Cat-Plugin](https://github.com/a1928370421/Bongobs-Cat-Plugin) by Weng Y
- Original release: [0.2.01](https://github.com/a1928370421/Bongobs-Cat-Plugin/releases/tag/0.2.01)

## What it has

- Mouse movement mode
- 77-key keyboard mode

## How to install

1. Close OBS Studio.
2. Download or clone this repository.
3. Drag the `bin` folder into your OBS Studio installation folder.
   - Example: `C:\Program Files\obs-studio`
   - If Windows asks, choose to merge the folders and replace files.
4. Open OBS Studio.
5. Add the Bongo Cat source to your scene.
